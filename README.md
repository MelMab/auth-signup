# StockSave AI Backend
A fintech backend system that digitizes informal thrift savings. It allows customers to save money, track balances, and book food items, while enabling owners to manage transactions, inventory, and payments.

# Tech Stack
Node.js
Express.js
MySQL
JWT Authentication
Swagger (API Docs)
Paystack API (Payments)
# Features
User authentication (Customer & Owner roles)
Role-based access control
Secure password hashing and login
Savings deposit (Cash & Paystack)
Transaction history tracking
Inventory management (food items & quantities)
Booking system with balance deduction
